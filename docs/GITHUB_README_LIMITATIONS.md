# GitHub README visual boundaries

The profile uses native Markdown and supported HTML: headings, tables, links, `picture`/`img`, and optional `details`/`summary` disclosures. Five featured and five animated additional projects remain visible. Beyond projects has visible Education, Professional certificates, and Outside work subsections.

All thirteen displayed visuals use pre-rendered GIFs with complete PNG stills: the hero, ten project panels, applied-AI process, and research process. Desktop/mobile motion and still variants make **52 active assets: 26 GIFs and 26 PNGs**. Existing SVGs remain generator sources or archived alternatives; the README does not display them.

Each `picture` chooses a desktop/mobile GIF only when `prefers-reduced-motion: no-preference` matches. Mobile PNG and default PNG fallbacks preserve a complete still view. GitHub's live Markdown API was checked on 22 October 2026 and preserves these media conditions. GIF playback has no inline pause or step controls; unsupported media conditions fall back to the still image.

A normal GitHub README does not execute arbitrary page JavaScript, custom page CSS, interactive WebGL, or mouse-driven 3D scenes. Isometric geometry is a rendered illustration. GitHub does not promise animated SVG playback, so displayed motion is encoded in GIFs. These assets require no external statistics service, runtime script, or font service.

Project animations explain hybrid generative models, EstateScope property-price prediction, VeggieAI, HDB analytics, consumption forecasting, student-performance analytics, HaikuForge, newspaper restoration, FitnessQuest, and Pendulum Learning Lab. They are not screenshots, recorded inference or policy rollouts, measured plots, or exhaustive architectures. The Pendulum illustration does not establish reward improvement or control stability. The applied and research processes describe working methods; they do not establish deployment or publication status. See [evidence and boundaries](./TRUTH_GROUNDING.md).

Essential facts, process stages, and project links stay in native text. Leaf-detection, historical learning-loop, and Curiosity Knot assets are outside the active inventory and current reading path. See [accessibility notes](./ACCESSIBILITY.md).
